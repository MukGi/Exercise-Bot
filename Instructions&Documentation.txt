Chatbot Features:
-Greeting Response: The chatbot has different responses for different greetings
-Workout Response: Responds to User Requests about workouts for various parts
-Negation check: Detects if user does not want to do a certain exercise, and recommends something else.
-Uses Part of Speech tagging to get the grammatical context of the user's input
-Alternative Choice: The bot has a wider range of response for when users don't want to do certain exercises

NLTK Features Used:
Part of speech tagging: pos_tag
Tokenization
Stemming
Lemmatization
